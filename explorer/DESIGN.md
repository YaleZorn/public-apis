# Stackpick design

## World

Blueprint drafting table: deep navy paper, cyan construction grid, cadmium highlighter actions.

## Type

- Display / UI labels: Chakra Petch
- Body: Source Sans 3

## Color

- Paper `#071A2B` / `#0C2740`
- Ink `#E7F0F7` / dim `#9BB4C8`
- Cyan `#5EC8E8`
- Mark `#F5C518`

## Components

- Filters sit on a ruled panel, not cards.
- API rows are list rows with metadata chips.
- Partner placements use a small yellow Partner tag.
- Stack is a right drawer; account/sign-in is a single highlighted panel; owner ops live in a footer disclosure.

## Motion

- Hero rise stagger
- List fade-in
- Drawer slide-in
- Respects `prefers-reduced-motion`
